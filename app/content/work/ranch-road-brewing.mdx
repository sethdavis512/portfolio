about: "Ranch Road Brewing Co. is a self-initiated concept, and the brewery is fictional: a marketing site for a Hill Country taproom that its staff could run without a developer. Every route is a single splat route that looks up a Contentful page by slug and renders its ordered sections from a bank of eleven blocks, including a hero, tap list, events, food menu, FAQ, gallery, and call to action. Data blocks fill themselves: the tap list reads every beer by status and tap number, the event list resolves weekly repeats and drops past dates, and the menu groups itself by category, so editing one beer updates every page that shows it. The brand is built around Texas road signage, with a Ranch Road route marker for route 8 (a quiet nod to React Router 8), a mile marker post, and a double yellow center line, in a day theme and an after-dark theme."
learned: "The core of the build is a two-sided block registry. On the server, each Contentful content type has a Zod schema and a build function that maps the raw entry to a clean, serializable block, and anything that fails validation is skipped instead of thrown, so a half-finished entry never takes a page down. On the client, the registry is a mapped type over the block union, so a block without a component, or a component whose props drift from its block, fails the typecheck. Shared collections load at most once per request through a small memoized context. Recurring events taught me to keep a wall-clock time steady across daylight saving changes by correcting with the time zone offset. On the styling side, lone-star-ui ships an unlayered dark-mode rule that outranks Tailwind v4's theme layer, so I defined the palette once with light-dark() and pointed the library's tokens back at it. The whole Contentful space, including editor help text, widgets, photos, and seed content, is created by one Bun script against the Management API."
impact: "The concept shows how I would hand a small business a site it can maintain itself: the staff change the content, and the design stays consistent because they never touch it. Adding a new kind of section is one schema, one component, and one content type, and the type system points out anything missed. It also served as an upgrade of my Contentful starter to React Router 8.5, React 19.3, TypeScript 7, Vite 8, Tailwind 4.3, and Zod 4, with Vitest coverage for the block mappers and event scheduling."
